- Only a subset of test fixtures (such as `test/brain/evidence.test.ts`) explicitly sets `git config commit.gpgsign false`; fixtures like `test/worktrees/start.test.ts` run `git commit` with `-c user.email=...` alone and inherit global GPG signing.
- Observed in `ses_e072575eefferga8xZtupKoQwp` (521 hardware YubiKey OpenPGP signatures in 5 minutes) and `ses_e0c7cf14fffeM1sKR4xgkOMs50`.
- Run git-heavy suites with `GIT_CONFIG_COUNT=1 GIT_CONFIG_KEY_0=commit.gpgsign GIT_CONFIG_VALUE_0=false bun test` (alongside `-u GIT_DIR` if inside git hooks), and configure `commit.gpgsign=false` in new temp-repo test fixtures.
