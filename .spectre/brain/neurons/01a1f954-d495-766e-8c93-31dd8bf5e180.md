- Adding near-synonymous inline skills costs ~3 points of held-out `bm25-full` hit@1 per leaf and bloats every turn; `skills/catalog.ts` embeds only the 33 push triggers (`32` leaves + `communication`) into `agents/definitions/spectre.ts` under `CATALOG_TOKEN_CAP = 1,500` tokens.
- The 49 pull skills (`25` playbooks + `24` stack/visual/verification/design/writing skills) and `3` hubs (`spectre-mode`, `playbook`, `ripwire`) are discovered on demand via `tools.spectre.skills` (`search`, `list`, `inspect`) before calling `skill({ id })`.
- 84 definitions set `autoinvoke: false` so OpenCode omits them from `<available_skills>`; only `ripwire` declares `autoinvoke: true`, and `skills/index.ts` flips it to `false` when neither `SPECTRE_RIPWIRE` nor `PATH` resolves a `ripwire` binary.
