worktrees action=start migrates a branch that already exists and that no worktree holds: the worktree is cut from that branch instead of from base, base is not consulted, git switch without -c attaches it, and Opened reports the ref as cut rather than base; a branch a worktree already holds is still rejected and the message names that directory.
