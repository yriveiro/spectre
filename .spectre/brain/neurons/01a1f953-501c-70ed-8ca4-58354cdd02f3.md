- `sessionState` in `tools/definitions/routing/host.ts` walks `parentID` links to the root session's model (falling back to `ctx.model.default`) so subagents inherit the primary session's fallback model rather than their own.
- `resolveSessionDefaults` and `resolveConfiguredFallback` in `tools/definitions/routing/index.ts` (mirrored by `resolveEffectiveDraft` in `tui/data.ts`) clamp profile efforts to the session model's ladder, clear `crosscheck` and model pins, and emit `warnings`.
- `status: "setup"` is returned only when the project is unconfigured (`setup` unset, no inherited file, no models, no profiles) AND no usable active session model can seed defaults; syntax errors or structurally invalid profiles still return `status: "problems"`.
