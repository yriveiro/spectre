- `/pr` runs `collectPreflight` (`2.5s` timeout per probe, `GIT_TERMINAL_PROMPT=0`) so the session starts with branch, main-worktree check, `commit.gpgsign`, `ripwire` presence, and diff stats already in context.
- `commitChanges` stages only `commit.files` (`git add --`), skips re-committing when `HEAD` already carries the exact message with clean files, and directs GPG/pinentry failures to `yubikey_unlock`.
- On SSH push auth/SK refusals, `push()` verifies `gh auth status --hostname <host>` and retries once with ephemeral `-c url.https://<host>/.insteadOf=...` and `-c credential.https://<host>.helper=!gh auth git-credential` without mutating `.git/config`.
- `edit()` updates open PRs via `gh api repos/{owner}/{repo}/pulls/<n> -X PATCH --input -` to avoid `gh pr edit`'s `read:org` GraphQL failure and `gh api -f`'s `@file` interpolation; code changes require post-edit `ripwire . --quality-delta` and `ripwire . --affected=<paths>` validation entries.
