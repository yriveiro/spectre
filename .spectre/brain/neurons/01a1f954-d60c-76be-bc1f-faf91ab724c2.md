- Measured on PR #16 (`features/canvas.md`): `gh pr diff --patch` includes commit-message `-` bullets that silently miscount deletions (`56/18` vs true `56/15`); `canvas` `action: "diff"` parses raw unified hunks, cross-checks `gh pr view` counts, caches rows under `~/.local/share/spectre/cache/diff/<project-digest>/<token>/`, and validates every cited `pr` path and line.
- Artifact storage and in-place `update` identity (`art_...`, relative URLs only — never claim a browser opened) live in OpenCode's artifact service (`experimental.artifacts: true`).
- `report` and `diagram` render Mermaid to static SVG via `pele`, while `page` and `brain` attach installed `d3` (`vendor/d3.min.js`) so published artifacts make zero external CDN requests.
