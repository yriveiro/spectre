- In bare-backed layouts, OpenCode's `ctx.location.project.canonical` points at the bare repo (which has no `.git` entry), so `worktrees` passes `from: sessionDirectory` to `ctx.worktree.create` and locates `main` by `branch === "main"`.
- OpenCode's review-base detector rejects reflog creation hints ending in `HEAD`, so `attachBranch` resolves `origin/HEAD` via `git rev-parse --symbolic-full-name` (`refs/remotes/origin/main`) before `git switch -c`.
- `Bun.file(dir).exists()` is `false` for directories and `Bun.spawn` throws `ENOENT` on missing `cwd`; `worktrees` and pull-based `sessionReturn` (`prompt` + `execute.before` using `Effect.catchDefect` so `Tool.Error` propagates) probe via `stat().isDirectory()`, block `remove` on active/paused `/goal` loops, and escort sessions to `main` without fetching.
