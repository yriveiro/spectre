- Mutating `event.system` across turns in `session.context` invalidates the provider prompt cache for everything downstream, while ad-hoc `prompt` text mutations vanish across compaction.
- `session.context` writes only static per-agent contract prose (`contextRule(health)`, `shapeSkillTool`), whereas changing session reminders (`spectre.brain`, `spectre.effect-watch`, `spectre.end-of-work`) use `ctx.session.instructions.entry.put` and `entry.remove`, persisting across turns and compactions.
- Brain and Effect-watch prompt hooks skip child subagent sessions (`info.parentID !== undefined`) and `mnemonic` so arena and worker seats pay zero context dilution.
