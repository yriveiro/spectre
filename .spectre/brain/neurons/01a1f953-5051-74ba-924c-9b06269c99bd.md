- `tools/definitions/brain/evidence.ts` deletes `GIT_DIR`, `GIT_WORK_TREE`, `GIT_INDEX_FILE`, and `GIT_COMMON_DIR` before spawning `git` (`REPOSITORY_ENV`), verified by `test/brain/evidence.test.ts`.
- Fixture `git()` helpers in `test/brain/evidence.test.ts`, `test/worktrees/start.test.ts`, `test/goal/fixture.ts`, and `tools/definitions/worktrees/read.ts` pass `Bun.env` unstripped, so an exported `GIT_DIR` from `git rebase --exec` redirects fixture `git init`, `commit`, `branch`, `worktree add`, `stash`, and `config` (`user.email`, `commit.gpgsign`) mutations into the real repository.
- If running tests inside a git hook or `git rebase --exec`, strip `env -u GIT_DIR -u GIT_WORK_TREE -u GIT_INDEX_FILE -u GIT_COMMON_DIR` first.
