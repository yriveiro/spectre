- `BASES` in `tools/definitions/worktrees/classify.ts` cuts new worktrees from `origin/HEAD` (`origin/main`), so reading files on an un-pulled local `main` before `worktrees({ action: "start" })` primes the session with stale code (caused PR #132 `ses_e1150e32cffeUIQHNo5GmfQWg3` -> `ses_e103628d3ffe29t42EMbk7gURq` to re-introduce `pinned: true`).
- Verified at `v2.3.0:packages/core/src/session/move.ts:116-135` and `project.ts:44`: `SessionMove` queues a `steer` inbox handoff on active runners until the next safe boundary; once committed, `ctx.location.directory` and `ctx.location.project.directory` resolve to the worktree root while `project.canonical` stays `main`.
- Do not run destination-dependent relative calls (`tools.spectre.comments`, `prose`, `history`, `solidjs`) in the same `execute` script as `worktrees({ action: "start" })` or `session_move`, and pass explicit worktree paths when delegating from a parent still on `main` (`ses_e0d07415bffe4Icu7l1Ex7zYc2`, `ses_e96e8932affewzN4tuyB7yPF9j`).
